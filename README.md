# aria2-gui-gush
This is a custom vibe coded aria2 gui i call it "gush" that is easy to use on Linux.

Its a .sh (shell) file that lets you download files from browsers, you run it by making it executable on Linux, first thing that pops up is asking for a URL of the file you want to download, you can easily copy and paste to it.
Next its going to ask for a location to download to on your local machine, on KDE it openes the Dolphin file explorer to choose from.
After choosing its destination and downloading it, a popup will show up telling you if the download was successful or failed. 
You can check out the screenshots down below to find more.

Also please keep in mind that this is vibecoded as much I hate AI i had no other way around but to do it, i think AI can be great in making these small commandlines or small programs that makes daily life a bit easier.
